# 주식연계채권 주간 집계 앱 (CB · EB · BW)

DART 주요사항보고서 중 전환사채권·교환사채권·신주인수권부사채권 **발행결정 원본 공시**만 모아서 주간 양식 엑셀로 내려받는 Streamlit 앱입니다.

## 파일
| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 |
| `collector.py` | DART 수집·파싱 |
| `excel_writer.py` | 양식에 채워 넣기 |
| `template.xlsx` | 주간 양식(빈 양식) — 양식을 바꾸려면 이 파일만 교체 |
| `requirements.txt` | 패키지 목록 |

## Streamlit Cloud 배포
1. GitHub에 새 레포를 만들고 위 파일 5개를 그대로 올립니다.
2. share.streamlit.io → **New app** → 레포 선택, Main file `app.py` → Deploy.
3. 앱 **Settings → Secrets**에 아래 한 줄을 넣습니다.
   ```
   DART_API_KEY = "발급받은키"
   ```
   (안 넣으면 화면에서 매번 키를 입력하는 칸이 나옵니다)

## 사용
- 날짜는 기본으로 **직전 목~수**가 잡힙니다(수요일 당일 실행 시 그 주 수요일까지).
- **수집 시작** → **엑셀 다운로드**.
- 노란 칸 = 자동 추출이 불확실해 확인이 필요한 칸. 무엇이 문제인지는 `검토용` 시트의 "확인필요" 열에 있고, 같은 시트에 DART 원문 링크와 Put/Call/Refixing 원문 발췌가 있습니다.
- 주관사(H열)는 비워둡니다. 담당RM·담당부서는 "미분류"로 채웁니다.

## 수집 규칙
- 대상: 유가증권(Y)·코스닥(K) 법인의 `주요사항보고서(전환사채권/교환사채권/신주인수권부사채권 발행결정)`
- 제외: 보고서명이 `[`로 시작하는 공시 전부 — [기재정정], [발행조건확정], [첨부정정], [첨부추가] 등
- CPS(유상증자결정)는 수집하지 않음
- 제외된 공시 목록은 화면 하단 "제외된 공시"에서 확인 가능

## 알려진 한계
- 투자자, Put/Call, 할증률, Refixing 주기·상향 여부는 **공시 원문 문장을 규칙으로 읽는** 방식이라 표현이 특이한 공시는 틀리거나 비어 나올 수 있습니다(노란 칸으로 표시).
- 하향Refixing(액면가o) 칸은 자동으로 채우지 않습니다(기본 `-`). 70% 미만 조정 관련 문구가 보이면 노란 칸으로만 표시합니다.
- 투자자 이름은 "OO자산운용"이 여러 곳이면 `수성, 칸서스, 타이거자산운용`처럼 묶고, 그 외에는 (주)·주식회사만 떼고 그대로 둡니다.
- 수요일 당일 늦게 올라온 공시는 상세 API 반영이 늦을 수 있어, 그런 건은 원문으로 대체 추출하고 "상세API 미반영"으로 표시됩니다.

## 로컬 테스트(선택)
```
pip install -r requirements.txt
python collector.py --key 발급받은키 --start 2026-09-17 --end 2026-09-23
```
